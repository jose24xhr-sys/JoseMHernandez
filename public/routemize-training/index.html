Day 1 — Understand Routemize & the Customer Experience

Understand what Routemize does, how the software works, the main settings, and what happens from the moment a customer starts a booking until the appointment appears inside the platform.

FOUNDATION

1. What is Routemize?

  • AI-powered scheduling and route optimization.
  • Built for appointment-driven field service businesses.
  • Uses location, availability, service areas, working hours, and existing schedules.
  • Understand the core idea: Drive Less. Sell More.
Lead→ Booking Form→ Availability→ Appointment→ Route

2. General Platform Tour

Preview the different areas of Routemize without going too deep into advanced features yet.

  • Home / Dashboard
  • Calendar
  • Booking Forms
  • Team
  • Business Locations
  • Service Areas
  • Route Preferences
  • Notifications & Branding
  • Integrations
  • Analytics
  • Routy
  • Profile / Account
  • Mobile experience

3. Initial Account Settings

  • Plan and team size
  • Branding
  • Work hours
  • Starting location
  • First appointment and end-of-day configuration
  • User profile
  • Google Calendar connection
Key learning point Availability is not controlled by one setting. Several configurations can affect which time slots Routemize displays.

4. Service Areas & Booking Forms

  • Create or review a service area.
  • Create a basic booking form.
  • Configure an appointment type.
  • Review assignment behavior.
  • Open the public booking link and experience it as a customer.

  • DripJobs, Jobber, ProLine, GoHighLevel, PaintScout — integration ecosystem

Day 1 Outcomes

  • Understand the purpose of Routemize.
  • Know where the main settings live.
  • Create multiple test bookings.
  • See how configuration changes availability.

Primary Resource Getting Started with Routemize tutorial / Help Center guide.
Independent Practice Create a booking form, make at least three bookings, change working hours, check availability again, and write down anything that is unclear.

Day 2 — Features, Troubleshooting & Support Tools

Go deeper into the product: scheduling tools, different route objects, basic troubleshooting, Routy, Analytics, and the first Intercom workflows.

FEATURES

1. Advanced Scheduling Features

  • Swap appointments
  • Hands-Free Swap
  • Pull Route
  • Appointment management
  • Route adjustments
  • Assignment behavior
Use-case practice Start with a customer situation, then identify which feature should be used instead of learning each button in isolation.

2. Appointment vs. Job Stop vs. Estimate

ConceptFocus
AppointmentA scheduled customer event managed by Routemize.
EstimateA common appointment/service use case for contractors.
Job StopA route stop that can behave differently from a customer booking.

3. Basic Troubleshooting

No availability:

Work Hours→ Calendar→ Service Area→ Appointments→ Team→ Route Preferences

Address outside service area:

Address→ Territory / ZIP→ Booking Form
Support habit Do not guess. Inspect the configuration controlling the behavior and reproduce the customer's experience whenever possible.

4. Routy — AI Assistant

  • Find appointments.
  • Test supported scheduling actions.
  • Explore limitations.
  • Differentiate a Routy misunderstanding from a platform issue.

5. Analytics

  • See how booking activity is reflected.
  • Inspect source activity before explaining a metric.

Wednesday · August 26

Day 3 — Support Operations

Start converting product knowledge into a repeatable support process using real customer scenarios and internal resources.

SUPPORT

Core Topics

  • Intercom conversation handling
  • How to understand the customer's actual request
  • Ticket classification
  • Investigating customer accounts
  • Requesting screenshots, examples, dates, and appointment details
  • Using Help Center articles and snippets correctly
  • Writing internal notes
  • Recognizing when escalation is necessary

Case Review Exercise

Review real Routemize conversations and ask:

  • What is the customer asking?
  • What information is missing?
  • What would I check inside the account?
  • What resource should I use?
  • Would I resolve or escalate this?

Day 3 Goal

  • Follow the Routemize support workflow.
  • Find information before asking unnecessary questions.
  • Use internal resources correctly.
  • Collect useful evidence.

Friday · August 28

Day 5 — Supervised Customer Support

Start applying the week's training to real or simulated customer conversations, with review and coaching before becoming fully independent.

PRACTICE

Supervised Workflow

  • Shadow active customer conversations.
  • Identify the problem before reading the existing response.
  • Draft customer replies.
  • Handle low-risk how-to and configuration questions.
  • Practice requesting evidence.
  • Practice deciding whether to resolve or escalate.

End-of-Week Review

  • Review 3 difficult cases.
  • Review 1 strong response.
  • Review 1 escalation and why it was escalated.
  • Identify product areas that still need more practice.
  • Create a list of questions for Week 2.
Recommended Final Exercise Give 5–10 realistic Routemize customer scenarios. For each one, identify the issue, investigation path, response, and whether an escalation is needed.

End of Week 1

  • Navigate Routemize confidently.
  • Handle basic product questions.
  • Know where to find approved answers.
  • Perform basic troubleshooting.
  • Know when more investigation or escalation is required.
Week 1 target: product familiarity + structured support thinking, not complete independence yet.
